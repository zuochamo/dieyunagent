下面三个气泡展示思考区的卡片规则。
① 运行中：协调者把任务拆开并发派发，N 个子 Agent = N 张卡片（第 4 张见下）， 每个子 Agent 是一张大直角卡片（data-step-key="sa:<subagentId>"）， 该子 Agent 的全部轮次（思考 + 工具）都在卡片内的 .msg-thinking-subagent-body 里，随运行实时刷新（工具 pending → 完成）。 卡片正文按行定尺：固定 10 行（ --thinking-subagent-card-lines），超出走卡片内滚动—— 卡片出现即占满 10 行、高度恒定，不把卡片越撑越高、更不会把并发卡片互相顶下去。 卡片只是就地概览：完整过程看右侧面板「子代理」页（全部轮次、全文、不裁剪）。 运行中自动跟随最新一轮（用户上翻看历史时不抢滚动位置）。
② 已完成：run 结束，卡片仍是展开的直角卡片（不自动折叠），过程留在卡片内； 只有协调者自己的轮次收成一行摘要。
③ Plan 模式：写入子 Agent 也是同一套卡片，卡片标题统一为 「子 Agent 类型 + 子 Agent 序号」（.msg-thinking-subagent-name）： 调研 / 命令 / 写入 各有中文标签，序号在同一轮里全局唯一（勘察 #1、写入 #2、命令 #3）。
live-loop-trace.createSubagentNamer 一次分配 subagentId / 序号 / 类型三件套——身份与标题同源， 并发派发也不会撞 id（否则 4 个子 Agent 会被合并进同一张卡片）。
