1. 概述

叠云 Agent 是一个 本地优先的桌面 AI Agent：用户在 Electron 窗口对话；模型可调用本机工具；复杂任务走规划师 + 多子 Agent + Git Worktree 隔离。

一句话架构：主进程负责系统能力与安全边界 + Rust sidecar 编排；渲染进程负责 Agent UI 与 Gateway 客户端；本地 Gateway 用 WebSocket + RPC 桥接工具与记忆。

1.1 核心设计取舍

话题选择原因
Gateway 协议自研 WebSocket RPC轻量、与 Electron 解耦
Agent 循环Rust sidecar + Node LLM状态机可靠、UI 迭代快
路径安全白名单用户选工作空间即授权
复杂任务Planner + worktree并行与隔离
记忆Rust SQLite 唯一写入一致性与性能
定时任务单次 LLM可预测、低成本

1.2 安全模型

  • contextIsolation: true，nodeIntegration: false
  • 特权操作经 preload IPC 或 Gateway RPC
  • Gateway 仅 127.0.0.1 + token 鉴权
  • 文件/命令靠路径白名单 + 权限开关

表用途
