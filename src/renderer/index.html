使用说明

            

              
              
              
            

          

          

            

              

                

                  
概览

                  
叠云 Agent 是本地优先的桌面 AI 助手：在对话中调用模型，并通过本机 Gateway 读写工作区、执行 Shell、联网抓取、查库与浏览器自动化等。左侧为会话历史，中间为对话区，标题栏可打开工作区面板（文件 / 变更 / 终端 / 浏览器）。顶部菜单提供设置、手机连接与帮助。

                

                

                  
对话与 Composer

                  
输入框下方可选工作空间（本地文件夹或远程 SSH）、模型（Auto 或指定模型）、Agent / Plan 模式。支持粘贴或拖入图片作为附件；输入 @Codebase 可对工作区做语义检索。工作区面板「上下文」图标为圆环，指示当前上下文用量估算。

                  
Agent 模式：单 Agent 直接调用工具完成任务，改动写入当前工作区（非 Plan 隔离时）。

                  
Plan 模式：规划师拆解子任务，执行器在 git worktree 中并行改代码，规划师验收后在侧栏「变更」审核 diff，勾选应用已选写回主区或放弃全部。模式由输入框旁 Agent / Plan 切换决定，不会根据任务内容自动改道。

                  
普通任务支持撤回（还原本轮文件变更）与 Plan 中断后的检查点续跑；二者机制不同，检查点不能替代逐步撤文件。

                

                

                  
工作空间与侧栏

                  
本地文件夹：Agent 读写、Shell、索引均相对该目录；未选择时使用 ~/.dieyun/workspace/ 默认目录。

                  
远程 SSH：通过 SSH 连接远程主机并选择工作目录；支持记住登录、主机指纹校验、端口转发，以及远程 Agent / Gateway 部署。文件浏览、终端与工具调用在远程上下文中执行。内置浏览器在本机运行，因此在 SSH 工作空间里打开 localhost / 127.0.0.1 地址时会自动建立端口转发（优先占用同号本地端口）再加载，地址栏仍显示你输入的远端地址。

                  
侧栏四个视图：文件（层级浏览与打开）、变更（Plan worktree diff 与应用）、终端（交互式 Shell 输出）、浏览器（内嵌页面预览与自动化）。

                

                

                  
Worktree（Plan 隔离副本）

                  
是什么？Plan 模式下，执行器在 Git 仓库内的临时副本中改代码，不直接动主工作区。侧栏「变更」审 diff 后「应用已选」写回，或「放弃全部」丢弃。Agent 模式通常直接改主区，不创建副本。

                  
存在哪里？.dieyun/worktrees/{runId}/{执行器Id}/，位于当前 Git 项目根目录下。每次 Plan 对应一个 runId；需 Git 仓库，非 git 目录会降级为无隔离。

                  
日常怎么用？

                  
    
                    
  • 审改动 → 侧栏「变更」（看 diff、应用/放弃）
    • 
                    
  • 管磁盘 → 设置 → Worktree（列清单、删残留、设上限）
    • 
                  

                  
本机 vs 远程工作空间

                  
    
                    
  • 本地文件夹：设置页可列出并删除 .dieyun/worktrees 下的 run；与侧栏「变更」配合使用。
    • 
                    
  • SSH：Plan 在远程执行，副本在远程主机文件系统中。设置页无法列出远程副本（仅管理本机路径）；审改动仍用侧栏「变更」。若需在本机查看目录，请在 Windows 打开对应本地映射路径。
    • 
                    
  • 未设置工作空间：列表为空。请先在对话页顶部选择本地 Git 项目文件夹后再刷新。
    • 
                  

                  
设置 → Worktree 字段

                  
    
                    
  • 最多保留 run 数：超出按最旧删除；0 表示不限数量。默认 25。
    • 
                    
  • 总容量上限 (GB)：所有 run 合计上限；0 表示不限。
    • 
                    
  • 保存 / 立即按规则清理：保存并立刻清理；不会删侧栏「变更」中待审的 run（列表标「待审」）。
    • 
                    
  • 刷新列表 / 删除：查看遗留 run 与占用；待审 run 需先在「变更」应用或放弃。
    • 
                  

                  
自动清理时机：Plan 结束并应用或放弃后删除对应 run；保存设置或任务结束后按上限回收。异常退出可能留残留，可刷新后手动删或调低上限。

                

                

                  
模型设置

                  
定义模型：维护自定义 OpenAI 兼容接口（名称、Base URL、API Key），可为每个模型指定 Context 档位（未指定则按模型名推断）；保存后可在 Composer 模型列表中选择。

                  
向量索引：配置 Embedding 模型，供 @Codebase、codebase_search、长期记忆与技能语义召回使用。内置 bge-base-zh-v1.5（本地 ONNX）不可删除，需手动启用后才会生效；也可添加远程向量模型。

                  
供应商：添加多个 LLM 供应商接口，在编辑页手动「检测模型」后逐个启用；可为供应商设置默认 Context 档位，或为单个模型指定档位（未指定时按模型名推断）。Composer 的 Auto 与 Plan 规划师会从已启用的供应商模型与定义模型中自动选型。

                

                

                  
代码索引

                  
在右侧工作面板的「代码索引」页维护：查看状态、试搜片段、重建索引，以及开启保存后自动增量。代码索引把工作区源码切成可检索的片段（chunk）。Agent 问「某段逻辑在哪」时用 codebase_search 按语义/关键词找相关文件；它不画依赖图（那是「结构索引」）。

                  
语义检索依赖「向量索引」中已启用的 Embedding 模型（也可用关键词检索）。与结构索引互补：前者偏文本/语义搜片段，后者偏模块依赖与调用关系。

                  
自动增量更新（默认开）：保存源文件或打开工作区后，在后台增量更新索引（含向量）；需先对工作区完成一次「重建」。关闭后仅手动重建时更新。

                

                

                  
结构索引

                  
在右侧工作面板的「结构索引」页维护：查看状态、试查符号、重建索引，以及开启保存后自动增量。结构索引解析模块 import、函数/类符号与静态调用关系。Agent 用它查「谁依赖谁 / 谁调用谁 / 改一处会影响哪」；与「代码索引」互补（后者偏文本/语义搜片段）。

                  
本地分析 JS/TS/Python/Go/Rust，供 Agent 工具 graph（operation：module_deps / find_symbol / semantic_find / callers / callees / impact / lsp_callers）使用。

                  
语义找符号（graph 的 semantic_find）需先在「向量索引」中配置并启用 Embedding 模型；点击「重建」时会自动构建符号向量。

                  
与向量索引（@Codebase / codebase_search）相互独立，不依赖 MCP。SSH 工作区支持远程结构索引；graph 的 lsp_callers 在 SSH 下会使用远程 rg/grep 补强调用点。

                  
自动增量更新（默认开）：保存源文件或打开工作区后，在后台增量更新索引；需先对工作区完成一次「重建」。关闭后仅手动重建时更新。

                

                

                  
主题

                  
切换浅色 / 深色主题，调节字体大小（90%～150%）、窗口透明度（50%～100%）与色温（偏冷 / 中性 / 偏暖），均保存在本机。

                  
可单独设置思考 trace 的展示偏好：推理摘要、思考标题，以及 Shell / 编辑工具结果的默认展开状态。

                

                

                  
编码参数

                  
在「帮助 → 编码参数」按 Context 档位分别保存全部编码参数（模型与段预算、护栏、Harness 等）。在供应商/模型上指定档位后，对话会自动套用对应配置。修改后立即生效并保存到本机。

                  
档位说明：默认、16K、32K、64K、128K、200K、512K、1M、2M——各档独立保存，互不影响。8K 档已删除，旧数据自动并入「16K」；模型真实窗口更小时，可在「模型 → 上下文窗口」单独填写覆盖档位。「恢复当前」只重置正在编辑的那一档。

                  
模型与段预算（每档可调）：温度、上下文窗口、最大输出 Tokens、系统预留 Tokens、压缩触发比例、工具调用段上限、Agent 轮次段上限。切换 Composer 模型时会自动解析该模型绑定的档位；圆环上下文用量亦按当前档位估算。

                  
护栏与其它（每档可调）：工具护栏、Harness、UI 联动、上下文注入阈值、LLM 重试、编辑器与 Diff 等，同样随档位分别保存。

                

                

                  
权限

                  
本机权限：逐项开关 Agent 可用能力——本机控制、读/写文件、Shell、SQL Server 只读、联网抓取、浏览器自动化。关闭后对应工具不再注册。权限仅在本地回环 Gateway 中生效。

                  
启用 LSP 诊断注入（默认开）：发消息前拉取 TS/Python 等语言服务报错，注入 Agent 上下文（类似 Cursor Problems）；需本地工作区与读取文件权限。

                  
工位监控上报（默认开启）：内网 Socket.IO 实时上报 CPU / 键鼠统计，可在「设置 → 权限」关闭。

                  
长程 Agent 任务（默认关）：打开即生效，无需改编码参数。适合跨很多工具轮次的长任务：不启用文件回撤；撞上轮次上限时自动续段（最多 20 段）；不再硬拦同文件反复读取、只读探索步数、重复工具调用。每段工具次数与轮次上限自动提高。页脚显示「· 长程」。Plan 下 worktree 隔离仍有效；Agent 下建议在重要节点自行 git commit。

                  
另可设置开机自启（安装包环境；开发模式不可用）。

                

                

                  
知识

                  
三层持久化知识，在「设置 → 知识」维护：

                  
dieyun.md（~/.dieyun/dieyun.md）：跨项目个人规则与编码偏好。注入模式：始终 / 自动（编程类任务）/ 手动（@dieyun.md）。

                  
AGENTS.md（.dieyun/AGENTS.md）：当前工作空间项目地图（目录、命令、约定）；运行环境每轮自动检测。维护模式：自动合并 / 仅草稿 / 关闭；auto 模式下可开启采纳前 Diff 预览。

                  
Playbook（.dieyun/playbooks/）：可复用任务 SOP；Plan 验收或多步任务成功后可自动沉淀草稿，确认入库并在相似任务时语义召回。

                

                

                  
组件

                  
Monaco 与 Linux Node 从官方源按需下载；BGE 随安装包内置。是否启用请在「向量索引」中设置。

                  
在「设置 → 组件」查看健康、安装与运行状态；Monaco 与 Linux Node 支持重新下载或手动安装。

                

                

                  
技能

                  
技能存放在 ~/.dieyun/skills/，每个技能为子目录内的 SKILL.md。首次启动复制安装包预装技能，不覆盖已有文件。列表可搜索、分类、分页；支持从 skills.sh 市场安装，或本地「添加」创建。

                  
启用后 Agent 系统提示会注入技能摘要；复杂任务可按语义召回相关技能全文。

                

                

                  
MCP

                  
MCP（Model Context Protocol）连接外部工具服务。在列表中启用后，叠云启动对应进程并将其工具（mcp_* 前缀）注册到 Agent。支持本地命令、远程 HTTP/SSE，以及市场从官方 Registry 安装。部分服务需在环境变量或卡片配置中填写 Token / API Key。

                

                

                  
插件

                  
插件扩展 Gateway 能力（如数据库只读查询等）。本地已安装插件在列表中管理；市场可浏览官方与扩展目录（支持配置内网 catalog.json URL），一键安装到本地插件目录。

                

                

                  
定时

                  
按 RRULE 调度自动执行任务，保存在本机 plans.json。到点后创建专用会话，使用完整 Agent 工具循环执行，结果投递到指定对话。适合巡检、日报、定期同步等重复性工作。

                

                

                  
手机连接

                  
标题栏菜单「手机连接」展示内网 URL 与二维码。手机浏览器扫码后可查看会话、同步思考过程、发送任务与停止任务；实际执行仍在电脑端完成。需与电脑在同一局域网。

                

                

                  
帮助中心

                  
统计信息：Gateway 连接状态、今日按键与 Token、模型用量图表、工具 Harness 成功率等。

                  
运行日志：查看应用主进程与 Gateway 最近日志，支持刷新、清理与复制（默认保留 3 天）。

                  
编码参数：模型与段预算、Agent 护栏与上下文注入阈值等，详见上文「编码参数」小节。

                  
关于应用：当前版本与简要说明。关闭窗口后应用可驻留系统托盘，Gateway 与定时任务继续在后台运行。
