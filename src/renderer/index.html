使用说明

            

              
              
              
            

          

          

            

              

                

                  
概览

                  
叠云 Agent 是本地优先的桌面 AI 助手：在对话中调用模型，并通过本机 Gateway 读写工作区、执行 Shell、联网抓取与浏览器自动化等。左侧为会话历史，中间为对话区，标题栏右侧可打开工作区面板（变更 / 源码管理 / 终端 / 文件 / 产物 / 上下文 / 子代理 / 代码索引 / 结构索引等，SSH 工作空间另有 SSH 与浏览器视图）。顶部菜单只有三组：设置、连接（手机连接 · Agent 互通）与帮助。

                

                

                  
对话与 Composer

                  
输入框下方可选工作空间（本地文件夹或远程 SSH）、模型（Auto 或指定模型）、Agent / Plan 模式。支持粘贴或拖入图片作为附件；点麦克风图标或按 Ctrl+M 可语音输入（录完批量转写为文字）。输入 @Codebase 可对工作区做语义检索。工作区面板「上下文」图标为圆环，指示当前上下文用量估算。

                  
运行中继续说话：Agent 跑着时按 Enter 把消息排进队列，发送键临时变成停止；队列里的消息可逐条发送、编辑或清空。

                  
路径权限图标（输入框右侧的锁）：点一下等价于在「设置 → 沙箱」切到「完全放开」，或退回上一档；两处是同一个旋钮。

                  
Agent 模式：单 Agent 直接调用工具完成任务，改动写入当前工作区（非 Plan 隔离时）。

                  
Plan 模式：规划师拆解子任务，执行器在 git worktree 中并行改代码，规划师验收后在侧栏「变更」审核 diff，勾选应用已选写回主区或放弃全部。模式由输入框旁 Agent / Plan 切换决定，不会根据任务内容自动改道。

                  
普通任务支持撤回（还原本轮文件变更）与 Plan 中断后的检查点续跑；二者机制不同，检查点不能替代逐步撤文件。

                  
子代理：复杂任务里 Agent 可派生 subagent 并行干活，各自只回一份结论；进度与产出在侧栏「子代理」视图里看。

                

                

                  
工作空间与侧栏

                  
本地文件夹：Agent 读写、Shell、索引均相对该目录；未选择时使用 ~/.dieyun/workspace/ 默认目录。

                  
远程 SSH：通过 SSH 连接远程主机并选择工作目录；支持记住登录、主机指纹校验、端口转发，以及远程 Agent / Gateway 部署。文件浏览、终端与工具调用在远程上下文中执行。内置浏览器在本机运行，因此在 SSH 工作空间里打开 localhost / 127.0.0.1 地址时会自动建立端口转发（优先占用同号本地端口）再加载，地址栏仍显示你输入的远端地址。

                  
侧栏视图（图标自上而下）：变更（本轮与 Plan worktree 的 diff，可应用/放弃）、源码管理（git 状态与提交）、终端（交互式 Shell 输出）、SSH 远程（连接状态 / 远程索引 Agent / 会话副本，仅在远程工作空间出现）、浏览器（内嵌页面预览与自动化）、文件（层级浏览、打开与编辑）、产物（本会话生成或改动过的文件）、上下文（用量圆环、分段预算、压缩统计、记忆命中）、子代理、代码索引、结构索引。

                

                

                  
Worktree（Plan 隔离副本）

                  
是什么？Plan 模式下，执行器在 Git 仓库内的临时副本中改代码，不直接动主工作区。侧栏「变更」审 diff 后「应用已选」写回，或「放弃全部」丢弃。Agent 模式通常直接改主区，不创建副本。

                  
存在哪里？.dieyun/worktrees/{runId}/{执行器Id}/，位于当前 Git 项目根目录下。每次 Plan 对应一个 runId；需 Git 仓库，非 git 目录会降级为无隔离。

                  
日常怎么用？

                  
    
                    
  • 审改动 → 侧栏「变更」（看 diff、应用/放弃）
    • 
                    
  • 管磁盘 → 设置 → Worktree（列清单、删残留、设上限）
    • 
                  

                  
本机 vs 远程工作空间

                  
    
                    
  • 本地文件夹：设置页可列出并删除 .dieyun/worktrees 下的 run；与侧栏「变更」配合使用。
    • 
                    
  • SSH：Plan 在远程执行，副本落在远程主机的文件系统里，同一会话固定复用一份；本机没有对应目录。位置与未应用改动看侧栏「SSH 远程 → 会话副本」，审改动仍用侧栏「变更」。设置页只管理本机 .dieyun/worktrees，列不出远程副本。
    • 
                    
  • 未设置工作空间：列表为空。请先在对话页顶部选择本地 Git 项目文件夹后再刷新。
    • 
                  

                  
设置 → Worktree 字段

                  
    
                    
  • 最多保留 run 数：超出按最旧删除；0 表示不限数量。默认 25。
    • 
                    
  • 总容量上限 (GB)：所有 run 合计上限；0 表示不限。
    • 
                    
  • 保存并清理：保存上限并立刻按规则清理；不会删侧栏「变更」中待审的 run（列表标「待审」）。
    • 
                    
  • 刷新列表 / 删除：查看遗留 run 与占用；待审 run 需先在「变更」应用或放弃。
    • 
                  

                  
自动清理时机：Plan 结束并应用或放弃后删除对应 run；保存设置或任务结束后按上限回收。异常退出可能留残留，可刷新后手动删或调低上限。

                

                

                  
模型设置

                  
定义模型：维护自定义 OpenAI 兼容接口（名称、Base URL、API Key），可为每个模型指定 Context 档位（未指定则按模型名推断）；保存后可在 Composer 模型列表中选择。

                  
向量索引：配置 Embedding 模型，供 @Codebase、codebase_search、长期记忆与技能语义召回使用。内置 bge-base-zh-v1.5（本地 ONNX）不可删除，需手动启用后才会生效；也可添加远程向量模型。

                  
供应商：添加多个 LLM 供应商接口，在编辑页手动「检测模型」后逐个启用；可为供应商设置默认 Context 档位，或为单个模型指定档位（未指定时按模型名推断）。Composer 的 Auto 与 Plan 规划师会从已启用的供应商模型与定义模型中自动选型。

                

                

                  
代码索引

                  
在右侧工作面板的「代码索引」页维护：查看状态、试搜片段、重建索引；「保存后自动增量」开关在「设置 → 权限」。代码索引把工作区源码切成可检索的片段（chunk）。Agent 问「某段逻辑在哪」时用 codebase_search 按语义/关键词找相关文件；它不画依赖图（那是「结构索引」）。

                  
语义检索依赖「向量索引」中已启用的 Embedding 模型（也可用关键词检索）。与结构索引互补：前者偏文本/语义搜片段，后者偏模块依赖与调用关系。

                  
自动增量更新（默认开）：保存源文件或打开工作区后，在后台增量更新索引（含向量）；需先对工作区完成一次「重建」。关闭后仅手动重建时更新。

                

                

                  
结构索引

                  
在右侧工作面板的「结构索引」页维护：查看状态、试查符号、重建索引；「保存后自动增量」开关在「设置 → 权限」。结构索引解析模块 import、函数/类符号与静态调用关系。Agent 用它查「谁依赖谁 / 谁调用谁 / 改一处会影响哪」；与「代码索引」互补（后者偏文本/语义搜片段）。

                  
本地分析 JS/TS/Python/Go/Rust，供 Agent 工具 graph（operation：module_deps / find_symbol / callers / callees / impact / lsp_callers）使用。

                  
与向量索引（@Codebase / codebase_search）相互独立，不依赖 MCP。SSH 工作区支持远程结构索引；graph 的 lsp_callers 在 SSH 下会使用远程 rg/grep 补强调用点。

                  
自动增量更新（默认开）：保存源文件或打开工作区后，在后台增量更新索引；需先对工作区完成一次「重建」。关闭后仅手动重建时更新。

                

                

                  
主题

                  
切换浅色 / 深色主题，调节字体大小（90%～150%）、窗口透明度（50%～100%）与色温（偏冷 / 中性 / 偏暖），均保存在本机。

                  
可单独设置思考 trace 的展示偏好：推理摘要、思考标题，以及 Shell / 编辑工具结果的默认展开状态；也可关掉「显示完成验收提示」（每轮结束时按证据提示「做完了没」，只提示、不自动续跑）。

                

                

                  
编码参数

                  
在「帮助 → 编码参数」按 Context 档位分别保存全部编码参数（模型与段预算、护栏、Harness 等）。在供应商/模型上指定档位后，对话会自动套用对应配置。修改后立即生效并保存到本机。

                  
档位说明：默认、16K、32K、64K、128K、200K、512K、1M、2M——各档独立保存，互不影响。8K 档已删除，旧数据自动并入「16K」；模型真实窗口更小时，可在「模型 → 上下文窗口」单独填写覆盖档位。「恢复」只重置正在编辑的那一档。

                  
模型与段预算（每档可调）：温度、上下文窗口、最大输出 Tokens、系统预留 Tokens、压缩触发比例、工具调用段上限、Agent 轮次段上限。切换 Composer 模型时会自动解析该模型绑定的档位；圆环上下文用量亦按当前档位估算。

                  
档位在 Main 侧同样生效：这些值除了界面预算，也会写入本机 model-runtime-by-tier.json，主进程的压缩阈值、planner、定时计划都按同一档位读取——不是「只在界面上看起来按档」。

                  
护栏与其它（每档可调）：工具护栏、Harness、UI 联动、上下文注入阈值、LLM 重试、编辑器与 Diff 等，同样随档位分别保存。

                

                

                  
权限

                  
本机权限：读/写文件、Shell、联网抓取、浏览器自动化为系统内置能力，恒开、不提供开关（沙箱档位决定它们能越界到哪）。启用本机控制是总开关：关掉后 Agent 不能执行命令、读写本机文件、打开链接与浏览器，也不做电脑控制。权限仅在本地回环 Gateway 中生效。

                  
启用电脑控制（默认开）：允许 Agent 截屏并操作鼠标键盘；首次执行键鼠动作会先请求确认。

                  
代码索引 / 结构索引：这里管的是「保存后自动增量」，索引本身的查看、试搜与重建在侧栏对应视图。

                  
启用 LSP 诊断注入（默认开）：发消息前拉取 TS/Python 等语言服务报错，注入 Agent 上下文（类似 Cursor Problems）；需本地工作区与读取文件权限。

                  
工位监控上报（默认开启）：内网 Socket.IO 实时上报 CPU / 键鼠统计，可在「设置 → 权限」关闭。

                  
另可设置开机自启（安装包环境；开发模式不可用）。

                

                

                  
沙箱

                  
「设置 → 沙箱」决定 Agent 读写磁盘、执行命令、联网抓取的越界边界，改完即时生效。三档：只读（不落盘，写文件与会改文件的命令逐次确认）、工作区内可写（工作区内直接改；写工作区外、装进系统目录、联网等越界动作先问一次）、完全放开（整盘可写可跑，不再询问）。

                  
越界确认是 ask-once：批准按「本次会话 × 操作类别 × 所在目录」记住，换个任务或换个目录会重新问；没人可问（超时）即拒绝。无论哪一档，卸载、格式化、删系统目录这类高危命令都直接拒绝。输入框右侧的路径权限图标与这里同一件事。

                

                

                  
知识

                  
以下几类持久化知识，大部分在「设置 → 知识」维护：

                  
dieyun.md（~/.dieyun/dieyun.md）：跨项目个人规则与编码偏好。注入模式：始终 / 自动（编程类任务）/ 手动（@dieyun.md）。

                  
AGENTS.md（.dieyun/AGENTS.md）：当前工作空间项目地图（目录、命令、约定）。维护模式：自动合并 / 仅草稿 / 关闭；auto 模式下可开启采纳前 Diff 预览。文件上限 24,000 字（超出时按段裁剪，不再整段丢弃）；每轮只注入其中约 13,500 字的「概览 + 踩坑 + 命令」三段，其余段由 Agent 按需读取。维护记录只保留最近 5 条。

                  
长期记忆 · 项目记忆（自动沉淀）：跨会话的经验由归纳器写入两处 —— 用户级偏好在本机库（带语义索引，可跨项目召回），项目架构与踩坑在仓库里的 .dieyun/memory.md（人可读、可手改、可 diff、可提交）。Agent 也可用 memory_recall / memory_forget 主动查与忘；命中条数见侧栏「上下文」。

                  
定时知识归纳：可选 开启 / 闲时 / 关闭，并设置间隔与整理范围（近期对话、长期记忆、项目记忆、AGENTS.md）。归纳在后台由主程序执行，不依赖窗口开着；定时归纳用设置页的默认文本模型，每轮任务收尾的归纳跟随该轮所用模型。选「关闭」会同时停掉两者；「闲时」遇到任务进行中先跳过，任务结束后补跑。项目记忆落在仓库 .dieyun/memory.md，衰减与向量重建仍由程序执行。

                

                

                  
组件

                  
Monaco 与 Linux Node 从官方源按需下载；BGE 随安装包内置，缺失时可手动安装 zip。是否启用请在「向量索引」中设置。

                  
在「设置 → 组件」查看健康、安装与运行状态；Monaco 与 Linux Node 支持重新下载或手动安装。

                

                

                  
技能

                  
技能存放在 ~/.dieyun/skills/，每个技能为子目录内的 SKILL.md。首次启动复制安装包预装技能，不覆盖已有文件。列表可搜索、分类、分页；支持从 skills.sh 市场安装，或本地「添加」创建。

                  
启用后 Agent 系统提示会注入技能摘要；复杂任务可按语义召回相关技能全文。

                

                

                  
MCP

                  
MCP（Model Context Protocol）连接外部工具服务。在列表中启用后，叠云启动对应进程并将其工具（mcp_* 前缀）注册到 Agent。支持本地命令、远程 HTTP/SSE，以及市场从官方 Registry 安装。部分服务需在环境变量或卡片配置中填写 Token / API Key。

                

                

                  
定时

                  
按 RRULE 调度自动执行任务，保存在本机 plans.json。到点后创建专用会话，使用完整 Agent 工具循环执行，结果投递到指定对话。适合巡检、日报、定期同步等重复性工作。

                  
还有一种目标型任务：只写目标不起时间，配一条验收命令（退出码 0 即通过）与尝试次数、时间上限，Agent 会反复迭代直到验收通过或预算用尽；可为它指定工作区与模型。

                

                

                  
连接（手机 / Agent 互通）

                  
手机连接：标题栏「连接」→「手机连接」标签页展示内网 URL 与二维码。手机浏览器扫码后可查看会话、同步思考过程、发送任务与停止任务；实际执行仍在电脑端完成。需与电脑在同一局域网。

                  
Agent 互通：同一内网的多台叠云可以互相发消息。在「Agent 互通」标签页起个名字并勾选启用内网互通；对方首次来信时本机弹窗确认，不需要配对码，撤销授权后要重新确认。允许后对方消息投递到它单独的会话里；只有再勾选收到消息自动跑一轮，对方一句话才会直接触发本机执行——默认只收消息、不动手。

                

                

                  
帮助中心

                  
统计信息：Gateway 连接状态、今日按键与 Token、工具 Harness（近 200 次调用）的成功率与拦截、模型用量图表等；上下文压缩次数与成功率在侧栏「上下文」面板。

                  
运行日志：查看应用主进程与 Gateway 最近日志，支持刷新、清理与复制（默认保留 3 天）。

                  
编码参数：模型与段预算、Agent 护栏与上下文注入阈值等，详见上文「编码参数」小节。

                  
关于应用：当前版本与简要说明。关闭窗口后应用可驻留系统托盘，Gateway 与定时任务继续在后台运行。
